# 🐕 Где Димаса кусали псины (Чили 🇨🇱)

Интерактивная карта боевых похождений Димаса в Чили: хроника собачьих нападений, порванных штанин, спринтерских рекордов и стратегического убежища в Сантьяго.

## 📍 Локации на карте (в оригинале без скобок):
1. **🏰 Santiago, El Quisco 3260**
   - Координаты: `-33.411932, -70.596830` (Las Condes)
   - Статус: Главный командный бункер и безопасная зона.
   - Экипировка: +100 HP, целые джинсы, запас бинтов, пластырей и чилийского Писко. Псины сюда не суются!
2. **🐶 Pupuya**
   - Координаты: `-34.004167, -71.852765`
   - Пёс: *Дон Кусало де ла Пупуйя* (уровень ярости: 5/5 🐺)
   - Скорость Димаса: 39 км/ч (звуковой барьер).
3. **🏄‍♂️ Pichilemu**
   - Координаты: `-34.385169, -72.004661`
   - Пёс: *Эль Чоко Торпедо (Quiltro Costero)* (уровень ярости: 4/5 🐕)
   - Скорость Димаса: 34 км/ч.
